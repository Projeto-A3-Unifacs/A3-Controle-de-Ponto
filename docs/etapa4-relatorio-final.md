# Etapa 4 – Apresentação e Avaliação Final (Expo)

## 1. Objetivo da Etapa

Apresentar o projeto de software, com foco em:
- Aspectos de qualidade
- Gestão do processo
- Evolução do projeto ao longo das etapas

## 2. Visão Geral do Sistema

- Nome do sistema: Controle de Ponto
- Tecnologias:
  - Java + Maven
  - Banco de dados: PostgreSQL 
  - GitHub + GitHub Actions
- Principais módulos:
  - Registro de ponto
  - Cadastro de funcionários
  - Justificativa de atraso
  - Consulta de faltas e atrasos

## 3. Análise de Desempenho e Qualidade

### 3.1. Desempenho

- Tamanho do projeto (número de classes, pacotes)
- Tempo médio de execução dos testes
- Uso de recursos (compilação e testes via CI)

### 3.2. Qualidade do Produto

- Cobertura de testes (quando houver Jacoco ou métricas aproximadas)
- Robustez dos fluxos principais
- Tratamento de erros e mensagens ao usuário

### 3.3. Qualidade do Processo

- Uso de branches (`dev`, `main`)
- Pull Requests e revisões
- Automação com CI/CD
- Controle de versões via versionamento semântico

## 4. Comparativo: Início x Final do Projeto

### 4.1. Situação Inicial

- Ausência de CI/CD
- Poucos ou nenhum teste automatizado
- Ausência de padronização de commits

### 4.2. Situação Final

- Pipelines de CI/CD ativos
- Testes unitários e de integração implementados
- Padronização via Conventional Commits
- Releases automatizadas com changelog

## 5. Aprendizados e Melhorias Futuras

- Lições aprendidas ao longo da disciplina
- Dificuldades enfrentadas e como foram superadas
- Melhorias previstas:
  - ampliação de testes
  - refatoração de módulos

## 6. Conclusão

A etapa final consolidou não apenas o produto de software, mas também as práticas de engenharia utilizadas na sua construção, ressaltando a importância da integração entre desenvolvimento, testes e gestão de qualidade.
