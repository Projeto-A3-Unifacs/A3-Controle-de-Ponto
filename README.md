# Documentação do Projeto – Controle de Ponto

Este diretório reúne os documentos do trabalho da UC **Gestão e Qualidade de Software** (A3).

As etapas seguem a especificação do professor, incluindo:

- Configuração de CI/CD e DevOps com GitHub Actions
- Testes unitários, integração e uso de Mocks (Mockito)
- Garantia de qualidade, métricas e revisões
- Relatório final e apresentação (Expo)

## Arquivos

- `etapa1-devops-ci-cd.md` – Configuração do ambiente DevOps, CI/CD, conventional commits e versionamento semântico.
- `etapa2-testes-mocks.md` – Testes unitários, de integração e uso de Mockito.
- `etapa3-garantia-qualidade.md` – Relatório de testes, métricas de qualidade e revisões de código.
- `etapa4-relatorio-final.md` – Síntese final, análise de desempenho, qualidade e comparativo do início ao fim do projeto.
